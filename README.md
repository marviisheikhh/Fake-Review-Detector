# Fake Review Detector

An AI-powered web application designed to identify potentially fake online reviews using semi-supervised machine learning.

## Project Overview
Online fake reviews can mislead customers and affect business credibility. This project explores machine learning techniques to identify potentially deceptive reviews.

## Dataset

This project uses the Fake Reviews Dataset from Kaggle for training and evaluating the machine learning model.

- Source: Kaggle
- Dataset: Fake Reviews Dataset
- Contributor: Mexwell
- [View Dataset](https://www.kaggle.com/datasets/mexwell/fake-reviews-dataset)

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- TF-IDF Vectorization
- Positive-Unlabeled (PU) Learning
- Streamlit

## Project Workflow
1. Data collection and preprocessing
2. Exploratory Data Analysis (EDA)
3. Text feature extraction using TF-IDF
4. Model training using PU Learning
5. Model evaluation
6. Streamlit web application development

## Features
- Interactive user interface
- Text-based review prediction
- Detection of potentially fake reviews

## Run Locally
Install dependencies:
```bash
pip install -r requirements.txt
```
Launch the application:
```bash
streamlit run app.py
```

## Disclaimer
Predictions are model-based estimates and do not guarantee the authenticity of a review.
